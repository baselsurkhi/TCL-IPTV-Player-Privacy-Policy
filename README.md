# TCL IPTV Player – Media Player

## Overview

TCL IPTV Player is a media player application designed for mobile and TV devices.

The app allows users to load and play their own media content using external links, such as:

- M3U playlists  
- Direct streaming URLs  
- User-provided media sources  

## Important Notice

TCL IPTV Player does not provide, host, sell, or distribute any media content.

Users must provide their own content sources and are fully responsible for ensuring they have the legal rights to access and use the content they load into the app.

## Features

- Modern media player interface  
- Support for user-provided playlist links  
- Support for direct streaming URLs  
- TV-friendly navigation  
- Remote control / D-pad support  
- Mobile and TV layout support  
- Fast and lightweight playback experience  

## Supported Platforms

- Android  
- Android TV  
- Google TV  
- Amazon Fire TV  

## Not Supported

The following platforms require separate development:

- Samsung Tizen  
- LG webOS  
- Roku OS  

## Privacy

We respect user privacy.

TCL IPTV Player:

- Does not collect personal data  
- Does not track users  
- Does not store playlists on external servers  
- Does not share user data with third parties  

The app may temporarily process user-entered links locally on the device only for playback purposes.

## Permissions

The app may require:

- Internet access: to load user-provided media links  

No sensitive permissions are required.

## Disclaimer

TCL IPTV Player is a media player only.

We do not:

- Provide TV channels  
- Provide playlists  
- Host copyrighted content  
- Sell IPTV subscriptions  
- Control user-provided content  

Users are solely responsible for the content they add and play through the app.
